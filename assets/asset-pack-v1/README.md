# Original Asset Pack v1

This folder contains additional original, editable SVG artwork for Asset-game. It is a content-first deliverable: these are art sources and sprite sheets, not a playable game.

## Files
- `environment_atlas.svg`: 4×4 grid of 128×128 transparent-background urban props.
- `resident_variants.svg`: 4×4 grid of 96×96 transparent-background resident sprites with distinct clothing/hair palettes.
- `palette-and-usage.md`: art direction, cell layout, and integration notes.

## Art direction
Cozy modern Indonesian neighborhood, muted botanical greens, warm clay, cream plaster, dark forest outlines, and small amber accents. Keep silhouettes readable at game scale. All drawings in this pack are newly authored vector art; no game screenshots, ripped sprites, or third-party assets are included.

## Cell coordinates
SVG viewBoxes start at the top-left. Cell coordinates are zero-based. Each atlas has a visible grid guide only in its documentation; the SVG artwork itself has a transparent background and no grid overlay.
