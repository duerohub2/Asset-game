You may use, modify, and redistribute these assets as part of this project and its game builds. Keep this notice with redistributed source packs. Do not represent these assets as official artwork from another game or studio. No third-party game sprites, textures, logos, or ripped files are included.

This notice covers only the artwork authored in this repository, not external libraries or tools used by the project.
